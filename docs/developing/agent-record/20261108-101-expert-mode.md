# Expert mode

> S27 builds the first half of the expert mode in the app.
> The Card pane's Diagram toggle draws each card read-only as boxes and arrows: a box per line with its sentence, the result it works out and the results it reads, an arrow from a result to each line that reads it, and a dashed frame "Inside line N" around the lines inside every When, nested Whens included.
> Convert to node graph in the sheet toolbar's new Model actions menu and Edit as node graph beside the Diagram open one dialog with the gate's text, and both are disabled with the gate's tooltips for a sheet with an error or a skipped line.
> The copy opens on the canvas with each frame's members in a band of their own, the sheet held in memory beside it, and on native written beside the sheet's file.
> A banner names the sheet and the date and reads unedited, edited with node counts, original changed or original not found, and Open Game of Life and the sheet's line "Converted to node graph: Game of Life (expert)" switch between the two.
> Node headers show the display name over the raw kind for all 114 kinds, quick-add searches both, a Become's ports read "Line 2 when" and "Line 2 fired", and a frame is at least as wide as its title.

## Deviations

- **No model menu existed.** The plan puts Convert to node graph in "the sheet's model menu", and the sheet toolbar held only the name, Undo and Redo.
  S27 adds a menu at the toolbar's end, an icon named "Model actions" after the line menus' "Line N actions", holding Convert to node graph.
- **One Editor tab.** The expert design keeps the author document "open in its own tab", and the app has one Editor.
  The sheet is held in memory as the copy's counterpart, so Open original and the link switch between the two, each with its undo history.
  "Selected" in the acceptance is read as the copy shown in the Editor: as with every opened model, it installs on Apply.
- **Saved beside the sheet only on native, and only for a sheet opened from a file.** A browser writes no file beside another, and a sheet from New model or Edit model has no folder.
  Such a copy opens unsaved under `<id>_expert.toml`, which Save model suggests.
  A model save clears the remembered path, since the dialog can choose another folder.
- **The link line looks in memory only.** The sheet's "Converted to node graph: X" shows while the counterpart is its copy, and a sheet reopened from disk does not search its folder for copies.
  The copy's side does read the sheet from beside its file (`find_original`).
- **Frame groups only for origin frames.** Arrange keeps together the frames that record sheet lines, as a copy's do.
  A frame drawn by hand, as in the SIR starter, makes no group, and the starters arrange as before.
  Grouping the SIR starter's hand frames moved its nodes so far that a region drag test lost its target.
- **Title widths in Arrange are estimated** (6.5 points a character), since placement runs without fonts. The drawing measures the title.
- **Frames the expert draws stay editable (D25) by construction.** The app neither draws nor renames a frame, so a converted frame's title stays as written, and no frame editing was added.
- **Topic file.** The plan names `agents/henad-app-sheet.md` for the Graph view, and S19 moved the Card pane to `agents/henad-app-card.md`, which takes the Diagram.
- **Port names.** The Become's `rule.<id>.to` inputs keep their raw names, since C6 names only `when` and `fired`.
- **File and test names.** The Diagram lives in `diagram.rs` as D95 says, and the test keeps the plan's name `the_graph_view_draws_one_box_per_line_and_edits_nothing`.

## Issues found & future directions

- **The Diagram climbs as a staircase.** Each box takes its own row, so a card of many lines with deep dependencies grows tall and wide, and in a narrow Card pane the right columns sit beyond the horizontal scroll.
  Packing boxes of different columns into shared rows, as the prototype does outside frames, would make it denser.
- **The sentence in a box wraps at 240 points**, and a long condition makes a tall box.
- **The banner's date is UTC.** A conversion just after midnight local time can read the previous or next day.
- **The copy file is written on the UI thread.** It is one small file, and a slow network folder would stall a frame.
- **A sheet with unsaved edits converts from its edited text.** Reopening the copy later beside the saved sheet then reads "has changed since this conversion".
