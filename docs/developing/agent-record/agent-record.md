# About records

This section contains records written (almost entirely) by LLMs after each session since 2026-08-12, usually used as a reference for agents themselves.

The records are included here for transparency only.
They are usually unnecessarily terse and often contain information that is not relevant to human readers, i.e. "AI slop".
Proceed at your own risk if you wish to continue to read them.

Some notes have a **Manual notes (Human)** section, which is written by humans to provide further information and how a human has been involved.
However, this usage is inconsistent.

The records of issue #48 cite the maintainer's unpublished design and audit documents.
A bracketed section number such as `[7.1]`, a question number such as `Q4` and an id such as `R-048` point into those documents, and nothing on this site resolves them.
The release checklist those records cite as `[5.5]` is published as [Releasing](../releasing.md).

See [AI usage](../contributing.md#ai-usage) for AI usage suggestions for Henad development.
