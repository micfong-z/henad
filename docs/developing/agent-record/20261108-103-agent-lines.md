# Agent lines

> S28 makes a card over agents as editable as a card over cells.
> The add buttons offer the agent lines of round 1 section 5, "+ Repeat..." comes after them on an agent card alone, and every new slot has its blank, select or picker.
> A look at agents starts with one average and names each summary after what it sums up ("average velocity", "centre", "push"), "+" adds another, and a select changes or removes one.
> A value can take the summaries and cells picked above, "length of my Velocity", a random number or direction, and "my new Velocity" only below the last line that changes Velocity.
> A problem the lowering finds in a line, such as a Set of a property that another line steers, now shows under that line.
> Tests rebuild the random walk and boids from a blank model of agents by accessible names and compare text and lowered code with the starters.
