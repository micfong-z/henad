# Security policy

Please report a vulnerability in Henad privately, through GitHub's private vulnerability reporting.
Open the [Security tab](https://github.com/micfong-z/henad/security) of the repository and select **Report a vulnerability**, or go straight to the [advisory form](https://github.com/micfong-z/henad/security/advisories/new).
Please do not open a public issue for it.
A public issue discloses the vulnerability before a fix is released.
