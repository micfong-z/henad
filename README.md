# Henad

**Henad** is a massive agent-based modelling engine that aims to be the most powerful and flexible ABM engine in the world on personal computers.

The current objective is to simulate agents on the order of 10 million at interactive speeds on a single laptop, with the ability to scale up to 100 million agents with more powerful hardware. This should come along with a web interface and the engine should be designed to be easily extensible and customizable by users. The engine preseves the WASM target to allow simulations to be run in the browser, and also supports native desktop applications.
