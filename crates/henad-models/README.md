# henad-models

[Henad](https://github.com/micfong-z/henad) is a parallel agent-based modelling engine, built to run millions of agents at interactive speeds on one machine.

This crate holds the example models: Game of Life, the SIR epidemic, boids flocking, ant foraging, Virus on a Network and Team Assembly on the CPU, and GPU ports of Game of Life, SIR, boids and ants.
The [model reference](https://micfong-z.github.io/henad/reference/models/) describes each one.
